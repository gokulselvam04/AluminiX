─────────────────────────────────────────────────────────────────────────────

When a user interacts with an AI-powered feature:

User Request
    ↓
API Handler (api/*.py)
    ↓
Services Layer (services/ai_client.py)
    ↓

    ↓

    ↓

User sees AI-enhanced result
