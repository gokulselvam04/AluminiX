AUTHENTICATION FLOW (UPDATED)
───────────────────────────────────────────────────────────────────────────────

USER SIGNS UP WITH GOOGLE:
  1. Click "Continue with Google"
  2. Google authentication popup
  3. User confirms scope permissions
  4. Returns to signup page
  5. ✨ POST-AUTH MODAL APPEARS ✨
  6. User sees: Name (auto-filled), Email (auto-filled), Department (required)
  7. User MUST select a department
  8. Validation ensures department is selected
  9. Submit button saves to Supabase + localStorage
  10. Smooth redirect to Dashboard

USER LOGS IN WITH GOOGLE:
  1. Click "Continue with Google"
  2. Google authentication popup
  3. Returns to login page
  4. System checks for existing user
  5. If department missing:
     → ✨ POST-AUTH MODAL APPEARS ✨
     → User selects department
     → Saves to database
  6. If department exists:
     → Direct redirect to Dashboard
  7. User session is complete

EMAIL/PASSWORD AUTH:
  1. User fills form with all fields
  2. Department is REQUIRED field
  3. Client-side validation enforced
  4. Supabase auth on server-side
  5. Database sync via /api/auth-complete-signup
  6. User redirected to Dashboard
